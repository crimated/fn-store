# FN Store Elite

Create a high-end premium Arabic gaming services website for a PUBG Mobile service store called:

FN STORE

The website sells:

1. PUBG UC top-ups
2. PUBG account ranking / pushing services

The goal is to create a website that looks expensive, professional, elegant, modern and trustworthy.

IMPORTANT:
This is NOT a typical “gaming website”.

Do NOT use:

* Excessive neon
* RGB colors
* Red/blue cyberpunk
* Skulls
* Flames everywhere
* Aggressive gaming clichés
* Excessive particles
* Cheap-looking gradients
* Huge glowing text
* Over-animated UI
* Random PUBG screenshots
* Generic AI-generated gaming artwork

The design should feel closer to:

Luxury e-commerce + premium gaming brand + modern Middle Eastern digital brand

The customer should immediately feel:
“هذا متجر مرتب، خدماته واضحة، والأسعار والخطوات كلها احترافية.”

Brand name:

FN STORE

Main tagline:

خدمات ببجي بمستوى مختلف

MOBILE EXPERIENCE

Mobile is extremely important because most customers will come from Instagram/TikTok/Snapchat.

On mobile:

* Perfect RTL
* Fast loading
* Large readable prices
* Cards should never feel cramped
* Buttons must be thumb-friendly
* Sticky bottom CTA can be used subtly
* Navigation becomes a clean mobile menu
* Modal must fit perfectly
* No horizontal scrolling

For package grids:

Desktop:
3 or 4 columns depending on screen size.

Tablet:
2 columns.

Mobile:
2 columns for UC packages if readability remains excellent.

Account services can use 1 column on smaller phones because their service names are longer.

⸻

ANIMATIONS

Animations must communicate quality, not excitement.

Use only:

* Smooth page entrance
* Small fade/slide
* Card hover
* Button transition
* Tab transition
* Modal transition
* Subtle background movement

Avoid:

* Constant floating objects
* Excessive particles
* Flashing
* Spinning logos
* Loading screens longer than necessary
* Huge animations

The website should feel fast and expensive.

⸻

BACKGROUND

Use a mostly dark neutral background.

Create depth using:

* subtle gradients
* shadows
* extremely faint grain
* soft radial lighting

No busy backgrounds.

No giant PUBG character covering the screen.

No copyrighted game screenshots unless real assets are later provided by the store owner.
